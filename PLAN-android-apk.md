# Plan: Build Android APK for Nadi Football Academy

## Goal

Create a native Android APK that wraps the existing React web app via **Capacitor**, connects to the backend API, and includes a **Demo Mode** for presenting to academy owners without a running backend.

## Architecture

```
React/Vite App (existing)
    ↓
Capacitor (wraps in Android WebView)
    ↓
Android APK (connects to backend OR runs in demo mode)
```

**Backend URL**: Configurable in-app — defaults to `http://10.0.2.2:8081/api` (Android emulator localhost) with option to set a custom URL.

**Demo Mode**: Mock API layer with realistic Tunisian football academy data, persisted in localStorage. All CRUD operations work locally.

---

## Files to Create/Modify

### 1. Capacitor Configuration

- **`frontend/capacitor.config.ts`** — Capacitor config with server URL, app ID `tn.nadi.academie`, app name "Nadi"
- **`frontend/package.json`** — Add `@capacitor/core`, `@capacitor/cli`, `@capacitor/android`, `@capacitor/status-bar`, `@capacitor/keyboard` as devDependencies

### 2. Demo Mode

- **`frontend/src/demo/mockData.js`** — Realistic mock data (20 players, 10 parents, 5 coaches, 15 payments, 8 slots, 4 categories) with Tunisian names, TND amounts
- **`frontend/src/demo/mockApi.js`** — Full in-memory CRUD API that mirrors the real API interface (getAll, getById, create, update, delete) with pagination, search, filtering
- **`frontend/src/demo/DemoProvider.jsx`** — React context that provides `isDemo` flag and overrides `api` axios instance with mock interceptors when demo mode is active
- **`frontend/src/demo/demoConfig.js`** — Demo mode toggle persistence in localStorage, backend URL configuration

### 3. App Modifications

- **`frontend/src/main.jsx`** — Wrap app with DemoProvider
- **`frontend/src/App.jsx`** — Add demo mode check, route for settings
- **`frontend/src/pages/Login.jsx`** — Add "Mode Démo" button + server URL config option
- **`frontend/src/components/Layout.jsx`** — Show "Mode Démo" badge in sidebar when active
- **`frontend/src/api/client.js`** — Conditional: use mock adapter when demo mode active

### 4. Android Build Infrastructure

- **`frontend/android.Dockerfile`** — Docker image based on `node:20` + Android SDK (commandlinetools, build-tools;34.0.0, platforms;android-34, JDK 17, Gradle 8.2)
- **`frontend/scripts/build-apk.sh`** — Script to build inside Docker: npm install → vite build → npx cap add android → npx cap sync → gradlew assembleDebug
- **`frontend/scripts/run-docker-build.sh`** — Host-side script that runs the Docker build and copies APK out to `build-output/nadi.apk`

### 5. Android Assets

- **`frontend/android/app/src/main/res/`** — Will be generated by `cap add android`, no manual creation needed
- **`frontend/public/icon.png`** — App icon (512x512) — will use a generated football-themed icon

## Docker Build Process

```bash
# From frontend/ directory
docker run --rm -v "$(pwd)":/app -w /app nadi-android-builder:latest bash scripts/build-apk.sh
# Output: build-output/app-debug.apk
```

The Docker image includes:

- Node.js 20
- JDK 17
- Android SDK (commandlinetools, build-tools 34, platform 34)
- Gradle 8.2
